# Orchestra Fingerboard Explorer

An interactive fingerboard guide for violin, viola, cello, and double bass. Choose a key, explore notes on the fingerboard, outline major or relative minor chord tones, and hear selected pitches.

## Publish with GitHub Pages

1. Create a GitHub repository named `orchestra-fingerboard`.
2. Upload `index.html` and `README.md` to the repository's top level and commit the files to the `main` branch.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/(root)`, then save.
6. After GitHub Pages finishes publishing, open the site URL shown on the Pages settings screen. It will be `https://YOUR-USERNAME.github.io/orchestra-fingerboard/` for a user account.
